# Cyber-Tamagotchi

Неоновый киберпанк-питомец для смартфона: Canvas, датчики движения, микрофон, Web Audio, localStorage, PWA. Без зависимостей и сборки.

## Управление
- **Тряхни телефон** — питомец получает энергию (на iOS датчик включается после первого тапа).
- **Тапай по питомцу / говори / дуй в микрофон** — растёт настроение.
- **Кормить, Играть, Сон/Свет** — быстрые действия. После 22:00 питомец засыпает сам.
- Уровни меняют форму и цвет свечения.

## Деплой на GitHub Pages
1. Залей содержимое папки в репозиторий (файл `.nojekyll` включён).
2. Settings → Pages → Deploy from branch → `main` / root.
3. Открой `https://<user>.github.io/<repo>/` на телефоне → «Добавить на главный экран».

Датчики и микрофон работают только по HTTPS (GitHub Pages подходит).
Для GitHub: загрузи `icons/social-preview.png` в Settings → Social preview.
